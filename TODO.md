# Project outcomes

- [x] **Brand Profile — Allow an organization to define legitimate assets such as company/brand name, official logo, official social-media accounts, official mobile applications, and other relevant brand identifiers.** Include validation and use configured assets to guide detection and exclude exact official assets.
- [ ] **Social Media Monitoring — Identify potential brand impersonation accounts, fake company pages, scam profiles, and accounts using similar names, logos, or branding.** Official accounts should not be flagged. Detect character swaps, added words, and spacing changes while avoiding over-flagging legitimate or normal names.
  - Remaining limitation: the public-source prototype can discover and cite indexed handle leads and score textual risk signals, but it does not collect/compare social-profile images; automated social-logo detection is not implemented.
- [x] **App Store Monitoring — Identify suspicious applications using similar app names, brand/logo impersonation, different developers or publishers, and app descriptions or branding resembling the legitimate company.** Official apps should not be flagged; source availability must be handled gracefully.
- [x] **Any-brand and suspicious-website discovery — Users can enter a brand name and get likely real social handles with source context and confidence, plus potential fake/suspicious brand websites or domains with risk indicators and supporting evidence.** Do not present uncertain candidates as verified facts; identify partial, unavailable, delayed or unsupported sources rather than inventing results.
- [x] **Readable investigation experience — Provide easy setup, prioritized findings with filters, risk scores, matched indicators, evidence, official-versus-suspicious status, and an understandable detail/review flow in a clean, attractive black-and-white interface.**
- [x] **Architecture and demonstration — Deliver the working prototype covering brand profile, social media monitoring, and app store monitoring; an architecture diagram covering data sources, detection logic, storage, and how official assets are excluded; and a short demo or a few slides showing the approach.**
- [x] **UI refinement — Keep the dashboard clean and attractive, and add 3D animations.** Preserve the monochrome brand style and support reduced-motion preferences.
